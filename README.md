# 🌍 Itinerarium

Itinerarium is a modern travel itinerary planner that helps users organize trips, create day-by-day travel plans, and access them on both web and Android devices.

## ✨ Features

- 📅 Create and manage travel itineraries
- 📱 Android application with Capacitor
- 💻 Responsive web interface
- 🎨 Modern and user-friendly design
- ⚡ Fast and lightweight

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Node.js
- Capacitor
- Android Studio

## 🚀 Installation

```bash
npm install
npx cap sync
npx cap open android
```

## 📱 Android

The web application has been converted into a native Android application using Capacitor.
